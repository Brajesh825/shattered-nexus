# Shattered Nexus: Controller & Keyboard Mappings

## 1. Core Controls
| Intent | Keyboard Keys | Gamepad (Xbox / PlayStation) |
| :--- | :--- | :--- |
| **Move Up** | `W`, `ArrowUp` | Left Stick Up, D-pad Up |
| **Move Down** | `S`, `ArrowDown` | Left Stick Down, D-pad Down |
| **Move Left** | `A`, `ArrowLeft` | Left Stick Left, D-pad Left |
| **Move Right** | `D`, `ArrowRight` | Left Stick Right, D-pad Right |
| **Confirm / Interact** | `Enter`, `Space` | **A** / **Cross** (Button 0) |
| **Back / Cancel** | `Escape`, `Backspace` | **B** / **Circle** (Button 1) |
| **System Menu** | `M` | **Start** / **Options** (Button 9) |
| **Cycle Character** | `Tab` | **RB** / **R1** (Button 5) |
| **Toggle Focus** | `` ` `` (Tilde) | **Select** / **Share** (Button 8) |

## 2. Context-Sensitive Actions

### 2.1 Exploration (Map)
*   **Move**: Use directional controls.
*   **Interact**: Press **Confirm** when near an NPC or object.
*   **System Menu**: Press **Menu** to open the pause menu.
*   **Quick Menu**: Press **Confirm** to interact with prompts.

### 2.2 Combat (Battle)
*   **Navigate Menu**: Use directional controls.
*   **Select Action**: Press **Confirm**.
*   **Cancel / Back**: Press **Back** to exit sub-menus (Abilities, Items).
*   **Cycle Target**: Use **Left/Right** during targeting mode.
*   **Confirm Target**: Press **Confirm**.

### 2.3 Party Menu
*   **Navigate**: Use **Left/Right** to cycle through party members.
*   **Close**: Press **Back**.

### 2.4 Story & Dialogue
*   **Advance Text**: Press **Confirm**.
*   **Skip Cutscene**: Click the on-screen "SKIP" button (Hotkeys pending audit).

## 3. Accessibility Notes
*   **Unified Focus**: The game uses a global focus management system. If you lose focus, press **Toggle Focus** (`` ` `` / **Select**) to regain control.
*   **Remapping**: Keyboard keys can be remapped in the **Controls** section of the System Menu. Gamepad bindings are currently fixed.
*   **Deadzone**: Gamepad sticks have a default deadzone of `0.2` to prevent drift.
